# Design Audit, November 2026

An audit of the library against [`guidelines/`](../guidelines/README.md). It lives in the repo only
and is not shipped in the npm package. Each finding cites a rule ID. Contrast ratios use the WCAG
2.x relative-luminance formula on the token values in `src/lib/styles/theme/`.

Status legend: ☑ done · ☐ open · ◐ partially done

Before/after screenshots of the first remediation pass were captured from Storybook with
Playwright. The stories covered are listed at the end.

---

## Remaining work, in suggested order

   Plan as one release with deprecation aliases.
2. A shared hover/active recipe for non-form components (#19).
3. RTL logical properties (#25).
